# minecraft-mod-I9-23G-123

Инструментальные средства разработки группа И9-23Г. Номер команды - 123.

### Название команды: Один в поле - воин

Перечень участников: Шелиховская

Цель: создать рабочий законченный мод

### Структура проекта:

Назначения

src/main/java - нахождение пакета с исходным кодом и точки входа
src/main/resources - нахождение конфигурационного файла проекта

Название добавляемого инструмента - leica

Назначение добавляемого инструмента - полив блока земли

#### Свойства инструмента:

максимум в стаке - 1,

прочность - 250

редкость - обычная

Назначение инструмента - поливать блоки земли/грязи

#### Рецепт и свойства объекта:

Данный инструмент создаётся по следующему рецепту:

![Лейка](craft.png)

Данная схема крафта неизменяема по порядку. Стоиомть рецепта обуславливается хорошими боевыми характеристиками лейки против эндерменов и эндердракона, что является наиболее эффективным оружием против них.

#### Требования совместимости:

Версия майнкрафт - 1.20.1

#### Установка:

Поместите файл мода .jar в папку mods игры или создайте её

#### Использование:

ПКМ по грядке - полив земли до максимума

ЛКМ по эндермену/эндердракону с лейкой в руке - повышенный урон по ним
